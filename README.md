# Sales Performance Dashboard (Excel)

## Project Overview

This project analyzes sales performance using Microsoft Excel and interactive dashboards. The goal is to track key business metrics, identify revenue trends, evaluate customer behavior, and support data-driven decision-making.

## Business Problem

Businesses need visibility into sales performance, customer activity, regional trends, and product performance to make informed decisions. This dashboard provides an interactive solution for monitoring these metrics.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Analysis

## Dashboard Features

* Total Revenue
* Total Orders
* Total Customers
* Average Order Value
* Revenue by Product
* Revenue by Month
* Revenue by Region
* Top Customers
* Interactive Filters

## Key Insights

* Identified top-performing products.
* Analyzed monthly revenue trends.
* Evaluated regional sales performance.
* Identified high-value customers.
* Examined payment method preferences.

## Business Recommendations

* Focus marketing efforts on top-performing products.
* Improve customer retention strategies.
* Expand activities in high-performing regions.
* Optimize inventory based on sales trends.
